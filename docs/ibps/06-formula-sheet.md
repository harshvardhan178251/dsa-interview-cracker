## Quant — arithmetic

| Relationship | Formula |
|---|---|
| Profit % | `(SP − CP) / CP × 100` |
| Discount chain | multiply: 0.8 × 0.9 = 0.72 → 28% off |
| Successive % change | multiply the factors: +10%, −10% → −1% |
| % of % | multiply: 25% of 30% = 7.5% |
| Loss on equal SP, x% profit & x% loss | `x² / 100` % |
| Average of averages | **weighted** by group size, never a plain mean |
| Speed ratio | same distance → speed ∝ 1/time; same time → speed ∝ distance |
| Average speed, equal distances | harmonic mean `2xy/(x+y)` |
| Time & work, A in a days, B in b days | together `ab/(a+b)` days |
| Alligation ratio | `(p₂ − p) : (p − p₁)` |
| HCF × LCM | = product of the two numbers |
| Probability, at least one | `1 − P(none)` |
| nCr | `nCr = nCr(n − r)` — use the smaller side |
| Circular arrangement | `(n − 1)!` |

### Quadratic (Vieta)

For roots x, y of `ax² + bx + c = 0`:

```
x + y        = −b/a
xy           =  c/a
x² + y²      = (x + y)² − 2xy
1/x + 1/y    = (x + y) / xy
(x − y)²     = (x + y)² − 4xy
```

For three roots x, y, z of `ax³ + bx² + cx + d = 0`:

```
x + y + z                = −b/a
xy + yz + zx             =  c/a
xyz                     = −d/a
1/x + 1/y + 1/z          = (xy + yz + zx) / xyz
```

## English — the seven rules, condensed

1. **Subject–verb agreement.** `number of` + singular; `a number of` + plural.
2. **Tense consistency.** One passage, one tense; past perfect for the earlier past event.
3. **Articles.** `a/an` for first mention; `the` for identified/unique; no article for
   generalisations.
4. **Prepositions.** at a point in time / on a day / in a period; at a place / in a larger
   place / on a surface.
5. **Dangling modifiers.** The phrase must attach to the subject of the main clause.
6. **Pronoun reference.** Number, gender and a real antecedent.
7. **Redundancy.** *return back*, *revert back*, *repeat again*, *new innovation*,
   *past history*, *final outcome*, *free gift*, *end result*, *future plans*.

## Reasoning — the shortcuts

| Situation | Rule |
|---|---|
| "Second to the left of" | pos(right) = pos(left) + 2 |
| "Third from the right" (n people) | pos = n − 2 |
| "Three people between A and B" | \|pos(A) − pos(B)\| = 4 |
| "A is second to the left of B" on a **circle, facing centre** | count counter-clockwise |
| "A ranks 12th from left, 18th from right" | total = 12 + 18 − 1 = 29 |
| Syllogism: "Some A are B" | ⇒ "Some A are **not** B" is always true |
| Syllogism: "All A are B" + "Some B are C" | ⇒ "Some A are C" is **NOT** guaranteed |
| Puzzle ordering | most-constrained entity first |
| Circular seating | fix one person to kill the rotation |
| Machine I/O | verify the pattern on the **last** pair |

### Syllogism conclusion types

```
A – B – C        all definite
Either A or B     exactly one
Either A or B, or both   at least one
Only A             A certain, B excluded
```

### Inequality

```
a/b > c/d   ⟺   ad > bc      (b, d positive)
a + b < c + d   ⟺   a − c < d − b
```

If it will not simplify, substitute values. Find two values that flip the order → the
answer is "cannot be determined".

## Exam traps — the final list

| Section | Trap |
|---|---|
| Quant | `0.2 × 0.3` computed as 0.05 |
| Quant | Average of two speeds taken as the arithmetic mean |
| Quant | Successive % changes added instead of multiplied |
| Quant | Approximating when the options are within 2% |
| DI | Scale errors — "in thousands" |
| DI | Caselet: not fixing a base unit |
| English | "Some A are B" treated as "All A are B" |
| English | An inference that is plausible but not necessary |
| English | Choosing the more obscure word rather than the correct one |
| Reasoning | "Second to the left" reversed |
| Reasoning | Ignoring a negative constraint |
| Reasoning | Circular seating without fixing a reference point |
| Reasoning | Finding the coding-decoding pattern from the first pair only |
| GA | CPI and WPI swapped |
| GA | REPO and reverse repo swapped |
| GA | The RBI asking for an OTP (it never does) |
| GA | Assuming SA = 0.25 in the Prelims Reasoning section — the marks are 40, so the penalty is **0.25 per question**, and each question is worth more than 1 mark in some sections. **Always read the marks column.** |

**The last trap is the important one.** In Prelims, Reasoning has 35 questions but 40
marks, so each question is worth 40/35 ≈ 1.14 marks and the penalty is still 0.25. But
in Mains, English has 40 questions for 20 marks — 0.5 marks each. The negative marking
is a flat **0.25 per wrong answer** in both papers, but the *value* of a correct answer
varies by section. Check the marks column before you decide whether to guess.
